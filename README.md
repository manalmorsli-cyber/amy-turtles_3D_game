# Amy and the Turtles - 3D Unity Game

## Project Overview

"Amy and the Turtles" is a 3D game developed using Unity, where the player controls Amy running through a desert environment.

The main objective is to collect coins while avoiding obstacles and enemies before the time runs out.

## Game Objective

* Collect **50 coins** within **1 minute**
* Avoid deadly obstacles (rocks, trees, boxes)
* Survive enemy attacks (turtles)

## Gameplay Mechanics

* Player movement:

  * Move left: `A` or Left Arrow
  * Move right: `D` or Right Arrow

* Health system:

  * Amy has **3 lives**
  * Colliding with turtles reduces health
  * Losing all lives = Game Over

* Timer:

  * 1-minute countdown
  * Game ends if time runs out

* Obstacles:

  * Instant defeat upon collision
  * Each obstacle has a unique sound effect

## Features

* Sound effects for each collision
* Real-time score tracking (coins)
* Health system (lives)
* Timer-based challenge
* Interactive 3D environment

## Technologies Used

* Unity (Game Engine)
* C# (Scripting)
* 3D Assets & Physics Engine
